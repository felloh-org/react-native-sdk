# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this package, please send an email to developers@felloh.com.

We will acknowledge your email within 48 hours and aim to provide a patch within 7 days.

Please do not disclose the vulnerability publicly until a fix has been released.

For security issues related to the Felloh hosted service, please contact security@felloh.com.
